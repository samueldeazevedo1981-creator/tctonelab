# Trucker Cap Tone Lab — Guia de Timbres

Versão atual do app estático. O usuário escolhe pedaleira, estilo e guitarrista e recebe uma receita inicial. As fichas completas de equipamentos e imagens de amplificadores e pedais ainda serão pesquisadas e adicionadas.

## GitHub e Vercel

1. Extraia o ZIP e envie o conteúdo da pasta extraída para a raiz de um repositório no GitHub.
2. Na Vercel, escolha **Add New > Project**, importe o repositório e selecione **Framework Preset: Other**.
3. Deixe Build Command e Output Directory vazios e publique. O arquivo `index.html` já está na raiz.

Para testar localmente, abra `index.html` no navegador. Nenhuma chave de API é necessária.

## Estado do conteúdo

As recomendações são pontos de partida. Modelos e efeitos com nome específico estão sendo conferidos nos manuais; capturas importadas dependem do conteúdo instalado na pedaleira. O app ainda não possui checkout, contas ou geração de arquivo de preset.
